BÚSQUEDA

A*

f(n) = g(n) + h(n)

Busca una ruta de menor costo entre estados utilizando el costo acumulado y una heurística.

  • Estado: servidor
  • Acción: transición
  • Meta: recuperación
  • Costo: conexión
ADVERSARIAL

Minimax

MAX ↔ MIN

Evalúa decisiones considerando que un adversario racional intenta producir el peor resultado para MAX.

  • Jugador MAX
  • Jugador MIN
  • Estados terminales
  • Función de utilidad

SEMANA 7

Representaciones del reconocimiento

Un mismo estado del servidor se representa mediante datos numéricos, hechos simbólicos y un autómata que analiza patrones temporales de anomalías.

DATOS DEL SERVIDOR

Analizar una observación

Ingresa las métricas actuales del servidor y una secuencia temporal utilizando N para estado normal y A para anomalía.

Ejemplo: NNAAA 
Ingresa los datos y selecciona "Analizar servidor".
REPRESENTACIONES

Tres formas de observar el mismo fenómeno

01

Numérica

Convierte temperatura, carga y errores en un vector y calcula su distancia respecto a valores de referencia.

02

Simbólica

Convierte los valores en hechos como temperatura_alta o carga_alta y aplica reglas comprensibles.

03

Autómata

Analiza una secuencia de estados normales y anómalos para identificar una anomalía persistente.
